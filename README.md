Practical Tutorial 04:Interactive Game Development with Expo Router 

RockPaperSnap ✊✋✌️

A mobile application built with **React Native**, **Expo**, and **Expo Router** as part of the Mobile Application Development Practical Tutorial 05 at the University of Kelaniya.

Features
* **Interactive Game Engine:** Play classic Rock-Paper-Scissors against the computer with real-time score tracking (Wins, Draws, Losses) using `useState`.
* **File-based Tab Navigation:** Seamless navigation between the Play Game arena and Rules screen using Expo Router Tabs.
* **Advanced UI Styling:** Styled using Flexbox, custom color palettes, responsive layouts, and vector icons.
* **Native Splash Screen:** Configured with a custom game logo and splash screen.

 Project Structure
* `app/(tabs)/index.tsx` - Main game play screen and game logic.
* `app/(tabs)/rules.tsx` - Scrollable game rules screen.
* `app/(tabs)/_layout.tsx` - Bottom tab navigation configuration.
* `Output_Screens/` - Folder containing application execution screenshots.
